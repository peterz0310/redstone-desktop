# Release notes

## 0.1.0 — early preview, not yet publicly released

- Build separate worlds and save areas to assign to your desktop.
- Wire buttons, levers, repeaters, redstone torches, lamps and Outputs; detect desktop files with pressure plates and sensors.
- Test circuits without opening files, reuse visual blueprints, and edit terrain with undo/redo.
- Explore forests, rivers, deserts, snowy ground and rare lava pools, with animation, particles and per-world daylight settings.
- Use original art and sound, or optionally import supported local Minecraft Java textures and short effects. No Minecraft assets are bundled.
- Open desktop files through circuits, with optional supported-shell script execution and exact-file approval.
- Export/import world libraries and preserve reset backups. Failed saves postpone Quit; oversized edits are refused before changing the build.
- Correct the reproduced audio-device-change crash and retain the working look when a replacement texture pack fails.
- Provide native Help and verified universal ZIP/DMG review packages with matching crash symbols and checksums.

This release is a preview. Older macOS/Intel execution, signed-download Gatekeeper acceptance and the remaining physical-Mac checks still need validation. Read [known limitations](docs/KNOWN_LIMITATIONS.md) and the [release checklist](docs/RELEASE_CHECKLIST.md) before public distribution.
