# Artwork and third-party notices

Redstone Desktop’s code, logo and original artwork are covered by the included MIT license. Interface symbols are provided by macOS. The app uses Apple’s system frameworks and includes no third-party runtime packages.

No Minecraft artwork, audio or game code is bundled. Optional textures and sounds imported from a local Minecraft installation or resource pack retain their original rights and licenses. Imports remain on the user’s Mac and are excluded from the app download and exported worlds. Resource-pack code is never executed.
