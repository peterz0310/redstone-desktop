# Known limitations and release gates

This is an experimental prototype; completed code/tests do not establish physical-Mac acceptance.

- Actual Finder coordinates on secondary/mixed-scale displays, window layering, Spaces, Mission Control, Stage Manager, sleep/wake and reconnect behavior require the [Mac checklist](TESTING.md). The public primary-upper-left conversion is a tested hypothesis, not a per-display calibration hack. If a physical mismatch appears, stop that mapping path and document it before using Outputs there.
- Desktop uses a logical-point virtual bounding canvas. Adding a display to the left/below can shift visible content. Physical gaps do not dispatch actions; mirrored identical frames draw once. Build Mode currently edits the primary screen only.
- Finder polling and file actions are asynchronous. Fresh reads, explicit permissions, exact-file approvals and bounded script execution can add latency. A held button extends a pulse; it does not create repeated rising-edge actions. Diagnostics Pause/Stop/reassignment cancel queued work.
- Pressure plates/file sensors observe Finder icon centers through polling, not live drag cursors or file-content watchers. Updates can take longer than 500 ms; stale/unavailable reads turn detectors off, and startup/recovery can produce Output rising edges. Extension filters cover ordinary files only. See [desktop detectors](DESKTOP_SENSORS.md).
- Redstone is the documented deterministic 2D model, not a complete Minecraft simulator: no height, piston/block updates, comparator, repeater locking, torch burnout or game-tick equivalence. Torches and Output rear-repeater pickup follow [the circuit rules](REDSTONE_RULES.md).
- Improved generation replaces historical terrain positions, including version-1 settings. Old unpainted ground can become water or scenery under circuits. Fresh worlds are recommended; no automatic library reset is performed. Rivers are contour-based 2D scenery, not simulated flow. See [World generation](WORLD_GENERATION.md).
- Default art/sound is original. Java imports require a local installation/pack and support a bounded subset of textures. No pack code executes. Minecraft dust and derived toolbar icons are explicitly bundled at the owner’s direction; [third-party notices](../THIRD_PARTY_NOTICES.md) identify it and exclude it from MIT. This does not establish redistribution permission from the rightsholder. Public distribution needs that asset decision resolved by the owner.
- Export is a validated whole-library JSON snapshot. Import adds independent world/area copies in Settings; a full reset-backup restore still requires the app to be quit. Start Over retains backups indefinitely, leaves TCC intact and cannot promise repeated macOS prompts. See [recovery](RECOVERY.md). Do not reset while other independent app copies use the same store.
- Profiling records an isolated renderer/simulator fixture and CPU/peak-RSS proxy, not battery watts or the full live Finder/desktop workload. Instruments/Activity Monitor and prolonged real use remain required.
- Minimum target is macOS 14; this implementation was built/tested on macOS 27 with Xcode 27. Older supported OS and Intel execution are not physically validated here. Deprecation warnings from the newer SDK remain for supported older audio APIs; this is not a compiler/test failure.
- CI is configured but a hosted GitHub run is not claimed until it actually runs. Local release archives are unsigned unless signing is explicitly configured. No Developer ID signature/notarization or internet release is claimed.

Pending physical checks remain unverified in TESTING.md until the owner confirms them. Backup/reset testing is explicitly deferred.
