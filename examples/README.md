# Original pack examples

`GrassOnly/` and `GrassOnly.zip` are the same tiny format-1 pack. They override only `terrainGrass` with original purple/teal checker art. Everything else falls back to the built-in assets. The art and manifest use this repository's MIT license. No Minecraft assets are included.

Choose either in Settings → Appearance → More options & custom packs → Choose Custom Pack Folder or ZIP…. Use Original Look restores defaults. See [the format guide](../docs/RESOURCE_PACKS.md) for making and sharing packs.
